Get into groups of 4 with your cards.

  1. What is the fewest questions that give all 4 of you different answers? Which ones?
  2. Find a question all 4 of you answer the same way.
  3. What’s special about your group? Write a rule \(\{\, x : P(x) \,\}\) that includes all 4 of you and nobody else in the room.

A Three-Set Puzzle

In all of \(U\) (\(100\) students), with \(P\) = has a pet:

\(\lvert C\rvert\), \(\lvert M\rvert\), \(\lvert P\rvert\) \(56\), \(45\), \(53\)
\(\lvert C\cap M\rvert\) \(31\)
\(\lvert C\cap P\rvert\) \(29\)
\(\lvert M\cap P\rvert\) \(23\)
\(\lvert C\cap M\cap P\rvert\) \(16\)

Fill in all eight regions. How many students are in none of the three?

Work from the middle out: centre 16; then the pairs minus the centre: C n M only 15, C n P only 13, M n P only 7; then each set minus its three inner regions: C only 12, M only 7, P only 17; total in C u M u P = 87, so none = 13. Check: 12+15+16+13+7+7+17+13 = 100. The three-set formula falls out: |C u M u P| = 56+45+53 - 31-29-23 + 16 = 87. Each region is one combination of yes/no answers on three of the six questions – the Venn regions are the cards, restricted to three columns.

The Empty Set, Subsets, and Power Sets

The Empty Set (\(\varnothing\))

Definition: \(\varnothing\) (a.k.a. \(\{\}\)) is the unique set with no elements.

  • Cardinality: \(|\varnothing|=0\).
  • Universal subset fact: For any set \(A\), \(\varnothing\subseteq A\).
  • But membership is different: \(\varnothing\in A\) only if \(A\) literally contains the empty set as an element.

Examples

  • If \(S=\{a,b\}\): \(\varnothing\subseteq S\), but NOT \(\varnothing\in S\).
  • If \(T=\{\varnothing,\{a\}\}\): \(\varnothing\in T\).

Operations with \(\varnothing\)

For any set \(A\):

  • Union: \(A\cup\varnothing = A\)
  • Intersection: \(A\cap\varnothing = \varnothing\)
  • Difference: \(A - \varnothing = A\), \(\ \varnothing\setminus A = \varnothing\)
  • Complement (in \(U\)): \(U - \varnothing = U\)
  • Cardinalities: \(|A\cup\varnothing|=|A|\), \(|A\cap\varnothing|=0\)

Element vs Subset

  • \(x\in S\) means \(x\) is one item in \(S\).
  • \(A\subseteq S\) means every element of \(A\) is in \(S\).

Examples (watch the braces!)

  • If \(S=\{a,b\}\) then:
    • \(a\in S\) is true; \(\{a\}\in S\) is false; \(\{a\}\subseteq S\) is true.
    • \(\emptyset \in S\) is false; \(\emptyset \subseteq S\) is true.
  • If \(T=\{\emptyset,\{a\}\}\) then:
    • \(\emptyset \in T\) is true; \(\{\emptyset\}\subseteq T\) is true.

Say aloud: “Curly braces change the type of thing. Elements vs sets of elements.”

Power Set

Definition: \(\mathcal{P}(S)\) = the set of all subsets of \(S\).


Example:

If \(S=\{a,b\}\), \(\ \mathcal{P}(S)=\) ________________________

 

Cardinality:

If \(|S|=n\), then \(|\mathcal{P}(S)|=\) ________________________

Why \(2^n\)?

Bitstring encoding:
Consider \(S=\{s_1,\dots,s_n\}\). For each subset \(T\subseteq S\) define an indicator of membership: \[(b_1,\dots,b_n)\ \text{where } b_i=\begin{cases}1,& s_i\in T\\ 0,& s_i\notin T\end{cases}.\]

How many subsets of a set of size \(n\)?

Connect to yesterday’s “\(b\) bits \(\Rightarrow 2^b\) codes.” Subsets \(\leftrightarrow\) \(n\)-bit strings. The ID cards are the example: each card is the set of questions that person answered yes to, a subset of the six questions. So the 64 possible cards are exactly P(six questions), and the card’s 6-bit # is its bitstring.

Cartesian Product \(A\times B\)

Definition: \(A\times B=\{(a,b)\mid a\in A,\ b\in B\}\)

Cardinality: \(|A\times B|=|A|\cdot|B|\).

Example: \(A=\{\texttt{iced},\texttt{hot}\}\), \(B=\{\texttt{Latte},\texttt{Tea},\texttt{Mocha}\}\).

 

Then \[A\times B= \{(\texttt{iced},\texttt{Latte}),(\texttt{iced},\texttt{Tea}),(\texttt{iced},\texttt{Mocha}),\] \[(\texttt{hot},\texttt{Latte}),(\texttt{hot},\texttt{Tea}),(\texttt{hot},\texttt{Mocha})\},\]

and \(|A\times B|=2\cdot 3=6\).

Design a Set

Using only the six questions, write a mask that selects:

  1. exactly the person on your card;
  2. exactly your person and your neighbour’s;
  3. nobody at all.
  1. An AND of all six answers (or fewer, if fewer already pin them down). Some can’t be isolated: 78 of the 100 share their card with someone (Amara & Ravi, Leila & Hana, and many more).

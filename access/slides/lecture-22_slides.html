Partition Identity

Story: Split iced orders by whether they’re non-dairy (\(N\)) or not (\(N^c\)). We should neither lose nor double-count any iced orders.

Theorem: For any sets \(I\) and \(N\), \[ (I\cap N)\ \cup\ (I\cap N^{c}) \;=\; I \quad\text{and}\quad (I\cap N)\ \cap\ (I\cap N^{c}) \;=\; \varnothing. \]

Apply:

  • Because the union is “disjoint”, \(|I| \;=\; |I\cap N| \;+\; |I\cap N^c|\)
  • This is the basis for the “Law of Total Probability,” which you will see someday!

Partition Identity Proof

Theorem: For any sets \(I\) and \(N\), \[ (I\cap N)\ \cup\ (I\cap N^{c}) \;=\; I \quad\text{and}\quad (I\cap N)\ \cap\ (I\cap N^{c}) \;=\; \varnothing. \]

Proof:

Consider arbitrary sets I and N. Union, two subsets. (subset) Let x be in (I n N) u (I n N^c). Then x is in I n N or in I n N^c; in either case x is in I. (superset) Let x be in I. By cases on x and N: if x is in N, then x is in I n N; if not, x is in N^c, so x is in I n N^c. Either way x is in the union. Intersection. Suppose some x is in both I n N and I n N^c. Then x is in N and x is in N^c, i.e. x is in N and x is not in N – a contradiction. So no x is in both: the intersection is the empty set. (Empty set is a subset of everything, so showing nothing is in it is the whole job.) Techniques: element-chasing for =, proof by cases (in N or not – excluded middle), proof by contradiction for “= empty set”.

Partition Identity Proof: Nothing in Both

The empty set \(\varnothing\) is the set with no elements. To show a set is \(\varnothing\), we show that nothing is in it.

Claim: \((I\cap N)\ \cap\ (I\cap N^{c}) = \varnothing\).

Proof (by contradiction): Suppose some \(x\) is in both \(I\cap N\) and \(I\cap N^c\).

  • Since \(x\in I\cap N\), we have \(x\in N\).
  • Since \(x\in I\cap N^c\), we have \(x\in N^c\), so \(x\notin N\).

So \(x\in N\) and \(x\notin N\), which is a contradiction. No \(x\) is in both, and the intersection is \(\varnothing\). \(\blacksquare\)

In code, this is a mask that selects nobody: ((I & N) & (I & ~N)).sum() is always 0.

Complement Flips the Order, by Contradiction

Theorem: If \(O\subseteq N\), then \(N^{c}\subseteq O^{c}\).

Proof (by contradiction): Suppose \(O\subseteq N\). Consider an arbitrary \(x\in N^c\), so \(x\notin N\). We show \(x\in O^c\).

Suppose, for contradiction, that \(x\notin O^c\). Then \(x\in O\).

Since \(O\subseteq N\) and \(x\in O\), we have \(x\in N\).

So \(x\in N\) and \(x\notin N\), which is a contradiction. Hence \(x\in O^c\), and \(N^c\subseteq O^c\). \(\blacksquare\)

Compare: the contrapositive of \(x\in O\rightarrow x\in N\) is \(x\notin N\rightarrow x\notin O\), which is the whole theorem in one line.

Repetition: *

a* means zero or more a’s: the empty string \(\varepsilon\), a, aa, aaa, …

 

* repeats the one thing just before it:

  • ha* matches h, ha, haa, … but not haha.
  • (ha)* matches \(\varepsilon\), ha, haha, hahaha, …
  • (a|b)* matches every string of a’s and b’s, including \(\varepsilon\).

 

Our first patterns that match infinitely many strings.

Shorthand: How Many

Everything from here on is shorthand for something you can already write.

  • a+: one or more. Same as aa*.
  • a?: zero or one. Same as “a or nothing”.
  • a{3}: exactly three. Same as aaa.
  • a{2,4}: two to four. Same as aa|aaa|aaaa.

 

colou?r matches color and colour.

ha+ matches ha, haa, … but not h.

Shorthand: Which Character

  • [aeiou]: one character from the list. Same as (a|e|i|o|u).
  • [a-z], [A-Z], [0-9]: one character from a range. \d means [0-9].
  • .: any one character.
  • [^aeiou]: one character not in the list.

 

[A-Z][a-z]* matches Tea and Latte, but not latte, LATTE, or Iced Latte (the space!).

c[^aeiou]t matches c9t and cxt, but not cat or ct.

... matches any string of exactly three characters.

A regular expression \(r\) does two different jobs.

  • Language. \(L(r)=\{w\in\Sigma^*: \text{the whole of } w \text{ matches } r\}\). A set of strings, usually infinite. In Python: re.fullmatch(r, w). In pandas: df['col'].str.fullmatch(r).

  • Filter. Keep the rows whose string has some part that matches \(r\). A set of rows, a subset of the dataframe. In pandas: df['col'].str.contains(r).


Today: languages first, then filters.

Regex vs. Language

Fix an alphabet of characters, \(\Sigma\).

Then a pattern \(r\) denotes the language \(L(r)=\{w\in\Sigma^*: \text{the whole of } w \text{ matches } r\}\)

  • if no string matches the pattern, \(L=\varnothing\)

  • the empty pattern matches only the empty string ⇒ \(L=\{\varepsilon\}\)

  • pattern a means \(L=\{\)a\(\}\)

  • Concatenated patterns AB means \(L(A)L(B)=\{xy:x\in L(A),y\in L(B)\}\)

  • Union of patterns: A|B means \(L(A)\cup L(B)\)

  • Kleene Star: A* means all finite concatenations from \(L(A)\) (incl. \(\varepsilon\))

Same spirit as set algebra: union / product / closure. No anchors here: a language always means the whole string.

Say the Set

 

(ab|ba)*: strings over {a,b} that are concatenations of ab or ba.


(0|1)*11(0|1)*: all binary strings containing 11 as a substring.


1(01|10)*0: binary strings that start with 1, end with 0, and are filled with {0,1} pairs that flip from 1 to 0 or vice versa.

Same Pattern, Two Jobs

pattern = 'Latte', so \(L(\)pattern\()=\{\)Latte\(\}\). How many café orders does each line keep? Predict, then run.

  • fullmatch is membership in \(L\): only Latte itself.
  • contains is a filter: it also keeps Iced Latte, Chai Latte, Matcha Latte. Those strings are not in \(L\). They are in \(\Sigma^* L\, \Sigma^*\), the strings with a part in \(L\).
  • Anchors turn a filter back into membership: contains('^Latte$') keeps the same rows as fullmatch('Latte').

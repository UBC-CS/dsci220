Friday’s Question

Is the converse true? Is every perfect square a glow number?

Yes. A perfect square is m^2 for a positive integer m, and m^2 = T_{m-1} + T_m, so the witness is k = m.

Both definitions are for positive integers, so 0 never comes up, and T_0 = 0 is defined, so 1 = T_0 + T_1 is a glow number.

The theorem and its converse together: the glow numbers are exactly the perfect squares. Proving the converse means naming a k for a given m – an existential, proved by giving the witness.

Warm Up

A Tower is built by stacking 5m red panels, and 7m blue panels.

What tower heights are possible? Talk it through with the people around you: which heights can you build, and which can’t you?

Give this time – it took a while last year. Let them find the last height that cannot be built (23) themselves.

End up with a clear claim: For all n > 23, we can build a tower of height n using only 5m red and 7m blue panels.

Every height \(n \geq 29\): ____________________________

24 = 2 red + 2 blue. 25 = 5 red. 26 = 1 red + 3 blue. 27 = 4 red + 1 blue. 28 = 4 blue.

Every n >= 29: n - 5 is at least 24, so a tower of height n - 5 can be built. Add one red panel.

Why FIVE base cases: each height comes from the height 5 below it, so the first five have to be checked by hand. Three is not enough – 28 would need 23, which cannot be built. (27 would need 22, which can be built, but the claim says nothing about 22.) Worth asking before filling in the table.

Point out the universal quantifier, and the least value. This is proof by cases plus one new move: assume it for a smaller value (n - 5). That is induction, before it has a name.

Aside, only if it comes up: 23 = 5*7 - 5 - 7.

Inductive Proof Skeleton Card

Proof by Induction of \(\forall n, P(n)\)

  1. First line: “Consider an arbitrary n.”
  2. Second line (IH): “Assume \(\forall j < n, P(j)\).”
  3. Determine exhaustive cases for \(n\), including one or more base cases and usually one inductive case.
  4. Prove each case, base and inductive, independently. Base case is typically direct, and inductive case will require use of IH.

Check the smallest cases. Assume the claim for the smaller pieces. Show it for the whole.

HW1: the WFFs a formula is built from. HW2: the two expressions joined by an and or an or. Today: the tower of height n - 5.

The name is structural induction when the smaller pieces are parts of the thing; induction on n when they are smaller integers. Same skeleton. HW2 promised “we will study it formally in a few weeks” – this is that.

WHERE HW1 USES THE IH – easy to miss. Write a for atoms, b for binary connectives; the claim is a = b + 1. Atom: a = 1, b = 0. No IH. ~A: negation adds neither, so the IH on A gives it directly. (A ^ B): a_T = a_1 + a_2 and b_T = b_1 + b_2 + 1. Those two are just counting – true of any formula, no IH. On their own they prove nothing. Subtract: a_T - b_T = (a_1 - b_1) + (a_2 - b_2) - 1. The claim says that difference is 1. The counting says how the difference COMBINES; the IH supplies the pieces’ values, a_1 - b_1 = a_2 - b_2 = 1, so 1 + 1 - 1 = 1. Without the IH nothing follows: a piece with 5 atoms and no connectives would leave the whole off by 4. The IH is what rules that out. “You used the IH without noticing” – worth saying out loud.

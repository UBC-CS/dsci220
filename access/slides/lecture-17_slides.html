Binary: an Application Interlude

Goals

  • Write numbers in binary. (This part is easy.)
  • Describe binary recursively, and prove things about it by induction.
  • Find bounds: how many bits a number needs, and how much \(b\) bits can hold.

Place Value

3 2 5 7

Ask a student to SAY the number: “three thousand, two hundred, fifty-seven”. Write the words under the digits as they say them: thousand, hundred, ten(s), one(s). Then the powers: 10^3, 10^2, 10^1, 10^0. Point: the words tell you what each digit means. Each place is worth 10 times the place to its right.

Instead of 10, Use 2

1 1 0 1

Same idea with 2: write eight, four, two, one under the digits, then 2^3, 2^2, 2^1, 2^0. One eight, one four, no two, one one: 8 + 4 + 1 = 13. Each place is worth 2 times the place to its right, and the only digits are 0 and 1 (bits). Data in a computer: charges read as 1 and 0. (Place-value tables from CPSC 203, 02_tue_representation.)

Place Value, in General

\[(b_{k-1}\dots b_1 b_0)_2=\sum_{i=0}^{k-1} b_i 2^i,\quad b_i\in\{0,1\}\]

Binary, Recursively

Chop the last digit off \(3257\):

\[3257 \;=\; 10 \cdot \boxed{\phantom{325}} + \boxed{\phantom{7}}\]


Chop the last bit off \(13 = (1101)_2\):

\[(1101)_2 \;=\; 2 \cdot \big(\boxed{\phantom{110}}\big)_2 + \boxed{\phantom{1}} \qquad\text{that is,}\qquad 13 \;=\; 2 \cdot \boxed{\phantom{6}} + \boxed{\phantom{1}}\]


For every \(n \geq 2\): \[n \;=\; 2\left\lfloor n/2 \right\rfloor + (n \bmod 2)\] The last bit is \(n \bmod 2\), and what’s left is \(\lfloor n/2 \rfloor\).

This slide is about NUMBERS: n = 2 floor(n/2) + (n mod 2). The next slide uses it to DEFINE the string. 3257 = 10 * 325 + 7: chopping the last digit divides by 10 and keeps the remainder aside. Everyone knows this. (1101)2 = 2 * (110)2 + 1, i.e. 13 = 2 * 6 + 1: in base 2, chopping the last bit divides by 2. Why it’s floor(n/2) and n mod 2: n = 2q + r with r in {0, 1} is division by 2 with remainder – the 3k / 3k+1 / 3k+2 cases from lecture 10, and mod from lecture 14. Quotient and remainder are unique, so q = floor(n/2), r = n mod 2. If anyone wants the general version: sum{i=0}^{k-1} b_i 2^i = 2 * ( sum{i=1}^{k-1} b_i 2^{i-1} ) + b_0 = 2 * (b_{k-1} … b_1)_2 + b_0 (pulling out the 2 shifts the index – the shifting trick from the summations video). Shift picture, as a backup: slide every bit one place right; each place value halves (eights become fours, …) and the ones bit falls off.

Definition: the Sequence of Mods

Keep halving, and record each remainder. The binary representation of \(n\) is the sequence of remainders, read from the last one back to the first:

\[\text{bin}(n) \;=\; \dots \;\; (\lfloor n/4 \rfloor \bmod 2) \;\; (\lfloor n/2 \rfloor \bmod 2) \;\; (n \bmod 2)\]

Recursively, writing \(\|\) for “followed by”: \[\text{bin}(1) = 1, \qquad \text{bin}(n) = \text{bin}(\lfloor n/2 \rfloor) \,\|\, (n \bmod 2).\]

The Definition Works

Recall: \(\;\text{bin}(1) = 1,\; \text{bin}(n) = \text{bin}(\lfloor n/2 \rfloor) \,\|\, (n \bmod 2)\), \(\;\) and \(\; n = 2\lfloor n/2 \rfloor + (n \bmod 2)\).

Claim: For every integer \(n \geq 1\), if \(\text{bin}(n) = b_{k-1}\dots b_1 b_0\), then \(n = \sum_{i=0}^{k-1} b_i 2^i\).

 

Proof: Consider an arbitrary \(n \geq 1\), and let \(\text{bin}(n) = b_{k-1}\dots b_1 b_0\). We show \(n = \sum_{i=0}^{k-1} b_i 2^i\).

IH: Assume that for every integer \(j\) with \(1 \leq j < n\), if \(\text{bin}(j) = c_{m-1}\dots c_1 c_0\), then \(j = \sum_{i=0}^{m-1} c_i 2^i\).

 

 

 

Case n = 1: bin(1) = 1, so k = 1, b_0 = 1, and 1 = 1 * 2^0. Case n >= 2: by the recurrence, bin(n) = bin(floor(n/2)) || (n mod 2), so b_0 = n mod 2, and bin(floor(n/2)) = b_{k-1} … b_1. 1 <= floor(n/2) < n, so the IH applies to j = floor(n/2), whose bits are b_{k-1} … b_1 (c_i = b_{i+1}): floor(n/2) = sum_{i=1}^{k-1} b_i 2^{i-1}. n = 2 floor(n/2) + (n mod 2) (the equation) = 2 * sum_{i=1}^{k-1} b_i 2^{i-1} + b_0 (IH at floor(n/2); b_0 = n mod 2) = sum_{i=0}^{k-1} b_i 2^i (2 inside, shift the index) The equation starts the chain: it’s what produces a floor(n/2) for the IH. The recurrence justifies the middle line: it says which bits floor(n/2) has. IH used at j = floor(n/2), not n - 1. Say so.

How Many Bits?

Let \(\text{bits}(n)\) be the length of \(\text{bin}(n)\): the \(k\) in \(b_{k-1}\dots b_1 b_0\). Since \(\text{bin}(n) = \text{bin}(\lfloor n/2 \rfloor) \,\|\, (n \bmod 2)\) adds one bit,

\[\text{bits}(1) = 1, \qquad \text{bits}(n) = 1 + \text{bits}(\lfloor n/2 \rfloor) \text{ for } n \geq 2.\]

A Bound on bits\((n)\)

Recall: \(\;\text{bits}(1) = 1,\; \text{bits}(n) = 1 + \text{bits}(\lfloor n/2 \rfloor)\), \(\;\) and \(\; n = 2\lfloor n/2 \rfloor + (n \bmod 2)\).

Claim: For every integer \(n \geq 1\), \(\quad 2^{\text{bits}(n)-1} \;\leq\; n \;<\; 2^{\text{bits}(n)}\).

 

Proof: Consider an arbitrary \(n \geq 1\), and let \(b = \text{bits}(n)\). We show \(2^{b-1} \leq n < 2^{b}\).

IH: Assume that for every integer \(j\) with \(1 \leq j < n\), \(\; 2^{\text{bits}(j)-1} \leq j < 2^{\text{bits}(j)}\).

 

 

 

So \(\text{bits}(n) =\) ____________, and \(\text{bits}(n) = O(\)____\()\).

Case n = 1: b = bits(1) = 1, and 2^0 <= 1 < 2^1. Case n >= 2: let m = floor(n/2). 1 <= m < n, so the IH applies to j = m: 2^{bits(m)-1} <= m < 2^{bits(m)}. By the recurrence: n >= 2, so bits(n) = 1 + bits(floor(n/2)) = 1 + bits(m). That is, b = bits(m) + 1, so bits(m) = b - 1, and the IH line becomes 2^{b-2} <= m < 2^{b-1}. Lower: n = 2m + (n mod 2) >= 2m >= 2 * 2^{b-2} = 2^{b-1}. Upper: m < 2^{b-1} and both are integers, so m <= 2^{b-1} - 1. Then n = 2m + (n mod 2) <= 2m + 1 <= 2(2^{b-1} - 1) + 1 = 2^{b} - 1 < 2^{b}. The equation n = 2m + (n mod 2) is used in both directions: >= 2m below, <= 2m + 1 above. The IH is used at j = floor(n/2) again. Take log2: b - 1 <= log2 n < b, so bits(n) = floor(log2 n) + 1, and bits(n) = O(log n). The size of a number’s representation grows like its log – last week’s asymptotics, in a data type. Checked numerically for n < 5000.

Capacity

How many different values fit in \(b\) bits? Let \(C(b)\) be the count.

\[C(1) = 2, \qquad C(b) = \boxed{\phantom{2}} \cdot C(b-1)\]

 

So \(C(b) = \boxed{\phantom{2^b}}\). The largest value is \((11\dots1)_2 = \sum_{i=0}^{b-1} 2^i = \boxed{\phantom{2^b - 1}}\).

C(b) = 2 C(b-1): every (b-1)-bit pattern, followed by a 0 or by a 1. C(b) = 2^b, by induction (same shape as the narrow-shelf Hanoi recurrence). Largest value: the geometric sum from lecture 12, 2^b - 1. That’s also the upper bound from the last slide with bits = b.

The Trick, Explained

Card \(i\) holds exactly the numbers whose bit \(i\) is \(1\). Its top-left number is \(2^i\).

 

  • Why does adding the top-left numbers give back the number?

  • Why are there exactly \(5\) cards for the numbers \(1\) to \(31\)?

  • How many cards would you need for \(1\) to \(1000\)?

Saying which cards it’s on is saying which bits are 1. Adding the 2^i for those bits is the place-value sum. 31 = 2^5 - 1 is the largest 5-bit value (capacity slide). 1000 needs bits(1000) = 10 cards.

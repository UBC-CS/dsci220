Reading a DFA

Goals

  • Read a DFA: run a string through it, and decide accept or reject.
  • Say what each state remembers about the string so far.
  • Go from a machine to a regex, and test the guess.

How to Read a DFA

  • Start at the start arrow.
  • Read the string left to right, one symbol at a time. Follow the arrow labelled with that symbol: 0 or 1.
  • At the end, a double circle means accept. Any other state: reject.


Trace 0110. Trace 1101.

0110: A, A, B, B, A. Ends in A: reject. 1101: A, B, B, A, B. Ends in B: accept. A remembers “the last symbol wasn’t a 1 (or nothing read yet)”; B remembers “the last symbol was a 1”. So the machine accepts exactly the strings that end in 1: (0|1)*1. Every state has exactly one arrow for each symbol. That’s the D in DFA: no choices.

Check!

A DFA is a for loop with one variable, and that variable can only take a few values.

The starting guess r’11’ disagrees on ‘011’: the machine accepts it, the regex doesn’t. Checking up to length 8 is evidence, not a proof. A proof is induction on the length of the string, with one claim per state (“after reading w, the machine is in R iff w contains 11”). That’s HW5.

DFA Ideas

Process a string from left to right, one character at a time.

  • State: what the prefix tells us so far.

  • Accept iff we finish in an accepting state.

  • Deterministic: at most one transition per symbol from every state.

  • Total: every state has a transition on every symbol.

DFA Definition

A Deterministic Finite Automaton consists of the following:

  1. a set of states \(S\)
  2. a finite alphabet \(\Sigma\)
  3. a transition function \(f\) that assigns a next state to each \((s, i)\) pair, \(s\in S\) and \(i\in \Sigma\).
  4. a start state \(s_0\)
  5. a set of accepting states \(F\subseteq S\)

Regex = DFA

A language is regular if and only if it is recognized by some DFA.

Closure Tricks

What’s closure?

  • Complement: make the DFA total (add SINK if needed), then flip accept to non-accept, and vice-versa.
  • Union / Intersection:
    States are pairs (p,q)
    • Union accepts if p ∈ F1 or q ∈ F2
    • Intersection accepts if p ∈ F1 and q ∈ F2
  • Difference: L1 - L2 = \(L1\cap L2^c\)

This mirrors set algebra directly; great place to reinforce recent set lessons.

Non-deterministic FA

NFAs

 

 

 

DFA: exactly one transition for each input symbol in each state.
NFA: may have multiple choices on a symbol and \(\varepsilon\)-moves (move without consuming input).

Acceptance: a string is accepted if there exists a path that reads all characters and lands in an accept state.

Say: “NFA is a modeling convenience. We’ll lean on that for regex to NFA construction.”

Notes on NFAs

  • Direct from a regex: Translate patterns piece-by-piece without tricky state discovery.

  • Local “gadgets”: Build tiny NFAs for literal, union (\(|\)), concatenation, Kleene star (\(^*\)) and wire together with \(\varepsilon\).

  • NFAs and DFAs have the same power!! (Kleene’s Theorem)

  • Build a DFA from NFA algorithmically if you need one.

Message: “We model the branching in the regex directly; acceptance means at least one successful path.”

Beyond Regular: Context Free Grammars

Why Regex/DFAs Can’t Do \(0^n1^n\)

Language: \(\{\,0^n1^n : n\ge 0\,\}\) (equal 0s followed by equal 1s)

Finite-state limitation:

Assume a DFA exists that accepts \(0^n1^n\), and let \(k\) denote its number of states.

Among the \(k+1\) prefixes \(0^0, 0^1, \dots, 0^k\) two must land in the same state.

From those two prefixes, feed the same number of 1s. One string should accept, and the other should not.

Not all languages are regular! No Pumping Lemma needed; it’s a pigeonhole/“can’t count unboundedly” story.

CFG Review

A context-free grammar (CFG) has:

  • Terminals (alphabet),
  • Nonterminals (variables),
  • Start symbol,
  • Productions like \(S \to 0S1 \mid \varepsilon\).

Notes:

  • A derivation rewrites nonterminals to produce a string.
  • A parse tree is evidence of how a string was generated.
  • The class of Regular Languages \(\subset\) the class of Context-Free Languages

Connect to your earlier WFF grammar: “That was a CFG all along.”

Closure Facts

If \(L_1, L_2\) are context-free:

  • Union: context-free via new start \(S \to S_1 \mid S_2\)
  • Concatenation: context-free via \(S \to S_1 S_2\)
  • Kleene star: context-free via \(S \to SS \mid \varepsilon\)

(Intersection with regular languages is CF; general intersection/complement are not.)
